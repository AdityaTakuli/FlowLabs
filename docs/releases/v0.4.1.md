FlowLabs trains machine learning models without code. Free and open source (MIT).

## What's new

**A user guide inside the app.** The new **Guide** section, next to Projects and SQL, explains
everything:
- getting started;
- bringing data and reading the Data page;
- building a pipeline, and code steps;
- training, every metric and chart, predicting and exporting;
- SQL and database connections;
- engines and GPUs, and updates;
- troubleshooting.

**Steps and models** lists every step and model with each setting and its default. It is generated
from the app itself, so it always matches your version. Search finds any word and opens the section
it is in. The **?** button in the top bar opens the guide at the page you are on.

## Install or update

If you have 0.4.0, click **Update to 0.4.1** in the top bar. Otherwise download the file for your
system below:

| System | File |
| --- | --- |
| Ubuntu, Debian | `FlowLabs-0.4.1-linux-amd64.deb` |
| Other Linux | `FlowLabs-0.4.1-linux-x86_64.tar.gz` |
| macOS | `FlowLabs-0.4.1-macos-arm64.dmg` (Apple silicon) or `-macos-x86_64.dmg` (Intel) |
| Windows | `FlowLabs-0.4.1-windows-x64-setup.exe` |
