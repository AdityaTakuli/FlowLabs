FlowLabs trains machine learning models without code: bring a table or a folder of images, clean
it, train several models side by side, see which one predicts best on rows it never saw, and export
it as Python that runs anywhere. Free and open source (MIT).

## What's new

**SQL.** A new SQL page next to Projects. Every dataset is a table you can query with DuckDB, joins
and window functions included, on copies of your data, so the files never change. Keep any result
as a new dataset and start a project from it. Connect a database you already have (PostgreSQL,
MySQL or MariaDB, SQLite, a DuckDB file, or any SQLAlchemy URL), browse its tables and query it.
Connections are read-only unless you allow changes. The editor completes table and column names,
and Ctrl+Enter runs the query.

**Updates inside the app.** FlowLabs tells you when a new version is out and installs it for you:
the .deb on Ubuntu and Debian (it asks for your password), the app on macOS, and the installer on
Windows. Downloads are checked against the release's SHA-256 checksums. You can turn the check off.

**A new look.** Cleaner surfaces in the light theme and a pitch-black dark theme. Charts are redrawn
and animate as they appear:
- a dotted score ring for the best model;
- histograms as columns of dots, split by the class you predict;
- density curves showing how well a model separates the classes;
- box plots of cross-validation folds;
- a bar and line chart comparing every model's score and training time.

Big numbers use a dot-matrix face. Controls slide between options.

**Fixes**

- If the Python chosen in the Engine menu lost numpy or pandas, FlowLabs starts its built-in engine
  instead of failing, and the error screen offers it too.
- Release uploads retry when GitHub times out.

## Download

| System | File | Install |
| --- | --- | --- |
| Ubuntu, Debian | `FlowLabs-*-linux-amd64.deb` | Double-click it, or `sudo apt install ./FlowLabs-*-linux-amd64.deb` |
| Other Linux | `FlowLabs-*-linux-x86_64.tar.gz` | Extract it, then run `sh FlowLabs/install.sh` |
| macOS, Apple silicon | `FlowLabs-*-macos-arm64.dmg` | Open it and drag FlowLabs to Applications |
| macOS, Intel | `FlowLabs-*-macos-x86_64.dmg` | Open it and drag FlowLabs to Applications |
| Windows 10 and 11 | `FlowLabs-*-windows-x64-setup.exe` | Run the installer |
| Python 3.11+ | `flowlabs-*.whl` | `pip install "flowlabs[deep,sql]"`, then `flowlabs app` |

The apps are not code-signed yet. The first time, macOS asks you to right-click the app and choose
**Open**; Windows SmartScreen needs **More info**, then **Run anyway**. From this version on,
FlowLabs updates itself.
