## SQL inside a project

A project's **Analyze → SQL** view now has the same query editor as the Databases page, for the
project's own data and for connected databases:

- **Run** runs the statement under the cursor (or the selection); **Run all** runs every statement,
  with one tab per result and a **Messages** list of what each statement did.
- **Stop** ends a slow query.
- **Explain** and **Explain and run** show how a query runs.
- **Export** to CSV, Excel, JSON or Parquet, and **Save as a dataset**, then **Use as this
  project's data**.
- A history of the queries you ran, and a choice of how many rows to show.
- **Sessions:** temporary tables, `SET` and transactions last from one run to the next, on your
  data (DuckDB) and on PostgreSQL, MySQL and other database servers, with Commit, Roll back and
  Auto-commit.

Ask AI writes the query into the editor and runs it; when a query fails, **Fix with AI** is in the
toolbar.
