FlowLabs: data, SQL and machine learning in one place. Free and open source (MIT).

## What's new

**Analyze, inside every project.** A new **Analyze** step, between Data and Pipeline.

- **Table:** the whole dataset as a grid. Sort by any column, search every column at once, and page
  through every row.
- **SQL:** query the project's data. It is the table `data`, and your other datasets and connected
  databases work too.
- **Results as data:** keep a result as a dataset, or make it **this project's data** with one click
  and train on it.

SQL used to be a separate page; it now lives in the project you are working on.

**Ask AI.** Type a question in plain English, such as *churn rate by contract type*. A model on Groq
writes the SQL, FlowLabs runs it, and a sentence explains the result. When a query fails, **Fix with
AI** corrects it. Bring your own free Groq key. Only table and column names, and a few common
category values, are sent; never rows of data.

**Charts you can explore.**

- **Expand** opens any chart full screen. Line and scatter charts there zoom with the scroll wheel
  and move when you drag.
- **Open in a new window** puts a chart in a window of its own (a second FlowLabs window in the
  desktop app), for another screen.
- The new **Charts** step gathers every chart of the project on one grid, with browser-style tabs:
  Overview, Data, Model, Compare and All charts.
- New charts: every metric for every model in one table, all models' ROC and precision-recall curves
  together, distributions of every column, and the most common values of category columns.

**Finding your way.** Under the step you are on, the left side lists that page's sections, and the
one you are reading lights up as you scroll. FlowLabs opens with a new intro, whose title scrambles
into place while Python loads.

**Guide.** Updated for all of the above, with a new page on Analyze and Ask AI.

## Install or update

If you have 0.4.0 or later, click **Update to 0.5.0** in the top bar. Otherwise download the file
for your system below:

| System | File |
| --- | --- |
| Ubuntu, Debian | `FlowLabs-0.5.0-linux-amd64.deb` |
| Other Linux | `FlowLabs-0.5.0-linux-x86_64.tar.gz` |
| macOS | `FlowLabs-0.5.0-macos-arm64.dmg` (Apple silicon) or `-macos-x86_64.dmg` (Intel) |
| Windows | `FlowLabs-0.5.0-windows-x64-setup.exe` |
