FlowLabs trains machine learning models without code: bring a table or a folder of images, clean
it, train several models side by side, see which one predicts best on rows it never saw, and export
it as Python that runs anywhere. Free and open source (MIT).

## Download

| System | File | Install |
| --- | --- | --- |
| Ubuntu, Debian | `FlowLabs-*-linux-amd64.deb` | Double-click it, or `sudo apt install ./FlowLabs-*-linux-amd64.deb` |
| Other Linux | `FlowLabs-*-linux-x86_64.tar.gz` | Extract it, then run `sh FlowLabs/install.sh` |
| macOS, Apple silicon (M1 and later) | `FlowLabs-*-macos-arm64.dmg` | Open it and drag FlowLabs to Applications |
| macOS, Intel | `FlowLabs-*-macos-x86_64.dmg` | Open it and drag FlowLabs to Applications |
| Windows 10 and 11 | `FlowLabs-*-windows-x64-setup.exe` | Run the installer (or unzip the `.zip` and run `FlowLabs.exe`) |
| Python 3.11+ | `flowlabs-*.whl` | `pip install "flowlabs[deep]"`, then `flowlabs app` |

The apps are not code-signed yet. The first time you open FlowLabs:

- **macOS** says it is from an unidentified developer: right-click the app, choose **Open**, then **Open** again.
- **Windows** SmartScreen warns about an unrecognised app: click **More info**, then **Run anyway**.

Your projects and datasets are kept in a `FlowLabs` folder in your home folder, so updating or
reinstalling the app keeps them.

## What's new

**Edit any step as Python.** Select a step or a model in the pipeline and switch to **Python** to
see the code it runs with your settings. **Edit as code** turns it into a code step you can change
line by line; the original stays in the pipeline, switched off, so you can go back. You can also add
code steps from scratch: cleaning (`clean(df)`), training rows (`rows(X, y)`), transforms (`fit` and
`transform`, or any scikit-learn transformer) and models (`model = ...`). Errors point at the line
that failed, and exported models run your code too.

**A new look.** The app is redesigned around the data: the home page opens on a spreadsheet you
can drop a file onto, projects and samples are tables with their best scores, the project steps sit
in a side rail with their status, and the pipeline is drawn on graph paper. Light and dark themes
follow your system, with a switch in the top bar.

**A real app window.** The desktop app opens in its own window on Linux, macOS and Windows instead
of a browser tab.

**Fixes**

- Neural networks fall back to the CPU when the Apple GPU (MPS) fails, instead of failing to train.
- Errors inside your own model code now name the line they came from.
- Tests and builds pass on Windows and macOS again.

## Use your computer's GPU from the browser version

Install with `pip install "flowlabs[deep]"` and run `flowlabs engine`. It prints a link that opens
FlowLabs connected to that computer, with its CPU cores and GPU.
