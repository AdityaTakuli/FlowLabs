FlowLabs: data, SQL and machine learning in one place. Free and open source (MIT).

## New on the Databases page

- **Back up and restore.** Save a schema (PostgreSQL) or database (MySQL, MariaDB) as a `.sql`
  file, built in with nothing to install, or with pg_dump and mysqldump when they are installed.
  **Restore** runs a backup in the database you choose: files from FlowLabs, pg_dump (plain text,
  or custom format with pg_restore) and mysqldump, gzipped or not. PostgreSQL restores can be all
  or nothing. Failed statements are listed with their line.
- **Table designer.** Create a table, or change one, in a form: columns, primary key, auto numbers,
  defaults, comments, indexes, foreign keys and checks. **Review changes** shows the exact CREATE
  and ALTER statements first, and only the ones needed.
- **ER diagram.** A schema's tables and the foreign keys between them on a canvas. Drag tables
  around (remembered), show keys only, find a table or column, double-click to open one.

Each schema or database has a menu with New query, New table, Diagram, Back up, Restore and Import.

## Updates

- **A progress bar while updating.** The update window shows how much has downloaded (percent and
  MB), then Install and Restart; the update button in the top bar shows the same, so you can close
  the window. (You will see it from the next update on: an update is shown by the version you
  have.)
- **The update window fits the app again.** It opened squeezed into the top bar, with its notes cut
  off.

## Fixes

- **MySQL strings with backslashes.** A string such as `'it\'s'` ended a statement early in scripts
  with several statements. MySQL's backslash escapes, PostgreSQL's `E'...'` strings and mysqldump's
  `/*!...*/` lines are now read the way the databases read them.
- **Query tabs no longer leave settings behind.** Closing a query tab, or running a restore, gave
  its connection back for browsing and editing with whatever it had set (`SET FOREIGN_KEY_CHECKS =
  0`, `USE`, table locks). Those connections are now closed instead.
- More query tabs can be open on one connection at once.
