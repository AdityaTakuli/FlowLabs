FlowLabs: data, SQL and machine learning in one place. Free and open source (MIT).

## Sheets: spreadsheets in FlowLabs

A new **Sheets** page (and **Analyze → Sheet** in every project) with spreadsheets that work like
Excel, built from scratch:

- **Formulas.** About 400 of Excel's functions, calculated the way Excel calculates them: XLOOKUP,
  VLOOKUP, INDEX/MATCH, SUMIFS and COUNTIFS, IF/IFS/SWITCH, LET and LAMBDA (with MAP, REDUCE, BYROW),
  dynamic arrays that spill (FILTER, SORT, UNIQUE, SEQUENCE, VSTACK, TAKE, GROUPBY), text (TEXTJOIN,
  TEXTSPLIT, TEXTBEFORE, REGEXEXTRACT), dates, statistics and distributions, and finance. Suggestions
  and argument hints while you type, colour-coded references, F4 for `$`, names, and references to
  other sheets.
- **Editing.** Excel's keyboard shortcuts, the fill handle (numbers, dates, months, days, "Item 1"),
  copy and paste with Excel, Google Sheets and web pages, Paste Special, Ctrl+Enter, Flash Fill, find
  and replace, Go To, notes, links and undo.
- **Formats.** Excel number format codes, fonts, colours, borders, alignment, wrap, merge, freeze
  panes, hidden rows and columns, and conditional formatting: highlight rules, top and bottom,
  duplicates, formulas, data bars, colour scales and icon sets.
- **Data.** Multi-level sort (by value, colour or month), AutoFilter, tables with banded rows and
  structured references (`Table1[Sales]`, `[@Units]`), data validation with drop-down lists, Text to
  Columns, Remove Duplicates, PivotTables with a fields pane, and charts (column, bar, line, area,
  pie, doughnut, scatter).
- **Files.** Open and save Excel `.xlsx` files and CSV. FlowLabs reads and writes `.xlsx` with its
  own code: values, formulas, formats, merged cells, widths, frozen panes, filters, tables,
  validation, conditional formatting and names.
- **Into models.** Open a dataset as a sheet, and save a table from a sheet as a dataset. In a
  project, use it as the project's data.

See the [Sheets](https://github.com/AdityaTakuli/FlowLabs/blob/main/docs/guide/sheets.md) guide.
