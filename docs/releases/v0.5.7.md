FlowLabs: data, SQL and machine learning in one place. Free and open source (MIT).

## An AI panel beside your work

The **AI** button in the top bar (or **Ctrl+L**) opens a panel on the right of every page, like the
assistant in a code editor. It sees what is open on the left and changes it for you:

- in a **SQL editor**, it writes or fixes the query, puts it in the editor and runs it (a query that
  changes data waits for you to run it);
- in **Sheets**, it writes values and formulas into the cells, and points out cells that show errors;
- in a **project**, it changes the pipeline: adds, changes or removes steps and models, sets the
  target, the metric or tuning, and trains, so *try extra trees and train* does exactly that.

Every change has Undo, and **Apply changes automatically** can be turned off to apply each one
yourself. The conversation stays as you move between pages. See
[the AI panel](https://github.com/AdityaTakuli/FlowLabs/blob/main/docs/guide/sql.md#the-ai-panel).

## Ask AI with the model you choose

Ask AI used to write SQL with Groq only. Now pick who writes it:

- **Groq** and **Google Gemini** (free keys), **OpenAI** (GPT-5, GPT-4.1), **Anthropic** (Claude
  Opus, Sonnet and Haiku),
- **GitHub Models**: GPT, Llama, DeepSeek and more with a GitHub token; Copilot plans get higher limits,
- **FreeLLMAPI** and **OmniRoute** running on your computer: one endpoint in front of many providers'
  keys, which pick a working model for you,
- **any OpenAI-compatible endpoint**: a company or reseller gateway, LM Studio, Ollama, vLLM.

Every provider comes with step-by-step instructions for getting its key, and **Load models** lists
what an endpoint offers. Each provider keeps its own key, model and address. Keys now live in the system keychain; a Groq key saved by
0.5.6 moves there by itself. Claude uses Anthropic's Python package, which the dialog installs the
first time. A ChatGPT, Claude or Copilot chat plan is not an API key: these services only let other
apps in through their APIs. See [Ask AI](https://github.com/AdityaTakuli/FlowLabs/blob/main/docs/guide/sql.md#ask-ai).

## Cloud storage you can browse

S3, Azure and Google Cloud Storage connections now open as folders in the SQL sidebar, with file
sizes. Click a Parquet, CSV or JSON file to see its rows, insert the SQL that reads it, import it as
a dataset, or query every file of a folder as one table. The desktop app ships DuckDB's storage
extensions, so this works on the first try without a download.

## Excel sheets and header rows

When an Excel file has several sheets, **Set up the project** lets you pick one, with each sheet's
size. Sheets without a table are skipped when importing, and a title or notes above a table are
recognised: FlowLabs finds the row with the column names by itself. Training, SQL and exports all
follow your choice, and projects already using a dataset keep their sheet.

## A quieter home page

The home page now shows only what you need: **Start** (new project, open a file with Ctrl+O, new
sheet, connect a database) and your **Recent** projects with their best score. **Samples** and
**Datasets** are one click away at the bottom. Drop a file anywhere on the page to start a project.

## Download a dataset

Every dataset (home page, **Datasets**) has a download button: CSV, Excel, Parquet or JSON.

## Fixes

- Works with DuckDB 2 as well as 1.x (DuckDB 2 changed how query results are read).
- Damaged or empty files (a broken .xlsx, an empty CSV, a file that is not really Excel) get a clear
  message instead of an internal error.
- Cloud storage folders and files with brackets, quotes or `*` in their names list and open.
- Storage errors say what went wrong ("Could not reach …", "refused the request: check the keys").
- Ask AI reads answers from models that reply in plain text or in a code block, and says so when a
  model answers without SQL.

- Installing a database driver works in the desktop app: pip is now inside it.
- The browser version loads the Excel reader again after a reload when a dataset needs it.
